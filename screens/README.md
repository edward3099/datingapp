# Expo Go App Screens

This directory contains screenshots and screen images from the Expo Go mobile app.

## Structure

- Place screen images here (PNG, JPG, or other image formats)
- Organize by feature or screen name if needed
- Add descriptions or notes about each screen as needed

## Upload Instructions

To upload screens:
1. Add image files to this directory
2. Use descriptive filenames (e.g., `home-screen.png`, `profile-screen.png`)
3. Optionally add a description in this README
